        Cost & latency

        Measured on this machine, after warm-up — the first CUDA call costs ~150 ms of kernel loading and would otherwise be reported as the model's latency. Latency is one query on its own: what a waiting user feels. Throughput is the amortised cost per user at batch 256: what an offline evaluation sweep costs. They differ by roughly an order of magnitude, and quoting the batched figure as "latency" would overstate responsiveness.

        Rating value distribution

        Ratings skew positive — 4 and 5 stars are over half the data. We use interactions as implicit feedback and ignore the value, which is standard for SASRec-style models.

        Interactions per user

        Every user has at least 20 ratings (MovieLens filters them), but the tail is long — the longest history is over 2,000. The model only sees the most recent 20.
